# 🎲 Помощник по правилам настольных игр

Поиск по правилам настольных игр с отображением страниц PDF.

## 🚀 Возможности
- Поиск по тексту правил
- Отображение страниц с найденными словами
- Поддержка нескольких игр
- Работает на любом устройстве

## 🛠️ Технологии
- **Frontend:** React + Vite
- **Backend:** FastAPI + Python
- **Database:** SQLite
